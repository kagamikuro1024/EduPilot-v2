Nguồn: `docs/specs/FEAT-weekly-exam/US.md` US-PE-08 AC1–AC20 + `SRS.md` 2 (ma trận quyền), 4.6 (điểm, ví dụ kiểm tay), 4.8 (đóng, chấm, công bố, kết quả, phúc khảo), 4.10 (thông báo, outbox, SSE), 5.8–5.14, 6.2 #40–#56, 6.4. D56. AGENTS "Cấm tuyệt đối": SV không thấy đáp án khi bài còn mở; điểm không do AI. Hộp đen; stack như `tc-US-PE-02.md` (cần `judge`, worker, Redis, Postgres).

Tiền điều kiện chung: bài thi `EM` loại MCQ (10 câu: 5 `MCQ_SINGLE`, 3 `MCQ_MULTI` (K = 2, 3, 3), 2 `TRUE_FALSE`) và bài `EC` loại CODE (2 bài × 5 test: trọng số 1,1,1,2,0 và 1,2,2,2,3), bài `EX` MIXED (ví dụ bắt buộc: Q1 1 đ MCQ_SINGLE, Q2 2 đ MCQ_MULTI K=3, Q3 3 đ code `[1,1,2]`, `max_score=10`). 6–30 SV (QC tạo tài khoản bằng SQL; `SVA`…`SVD` + SV phụ), 1 SV vắng, 1 SV `PENDING`. **Canary** (`QC-ANS-<uuid>`) ở `answer_key`, `explanation`, tên + input + expected test ẩn, lời giải mẫu, `override`, bài nộp SV khác (`QC-SUB-<uuid>`), sự kiện liêm chính, `similarity_reports`. **Điểm tính tay** bằng Python `fractions` (`scripts/p508-score.py`, QC tự viết, không dùng `exam_scoring.csv` của dev). Công cụ: **S** shell, **D** SQL, **A** Chrome, **G** `go test`, **P** Python, **R** Redis, **K** k6.
