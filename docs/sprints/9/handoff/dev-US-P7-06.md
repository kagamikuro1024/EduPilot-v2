# DEV handoff — US-P7-06 (Grading Engine: chấm mù, hai lượt, kiểm bằng code)
Nhánh `sprint/9-p7`. Spec: US-P7-06 AC1–AC12, SRS 4.6; TLR-4, 6, 8, 12, 16, 17d; proposals sprint 9 #4.

## Làm
- `internal/textfold` (mới): `Fold` = `vn_fold` của SQL (1:1 theo rune), `Collapse`, `Index` (vị trí **UTF-16 code unit** trong văn bản gốc để tô sáng), `Words`. `TestFoldParitySQL` so Go với `SELECT vn_fold()` trên bảng 67 ký tự + chữ hoa; `TestQuoteOffsetsUTF16`.
- `internal/grading` (mở rộng, không đụng phần trích công thức của P6):
  - `check.go`: `Check` (kiểm một lượt: id đủ / không lạ / không trùng, điểm decimal kẹp `[0;max]` + làm tròn nửa lên bước 0,25 → `SCORE_ADJUSTED`, trích dẫn có thật qua `textfold.Index` → loại + `EVIDENCE_NOT_FOUND`, `total` ≠ Σ → `TOTAL_MISMATCH` dùng Σ, `confidence` < ngưỡng → `LOW_CONFIDENCE`; `confidence` đọc `json.Number` rồi so decimal), `Merge` (draft = lượt 1; lệch > `GRADING_DISAGREE` ở tổng hoặc một tiêu chí → `NEEDS_REVIEW`; lượt 2 hỏng → giữ lượt 1 + `NEEDS_REVIEW`), `AnswerEcho` (≥ 12 từ liên tiếp). Mười một cờ là hằng `Flag*`.
  - `injection.go`: `InjectionPatterns` (bảng SRS 4.6.3 chép nguyên văn), `ScanInjection` (tách câu tay vì RE2 không có lookbehind; trả câu + mã mẫu + vị trí UTF-16); **không sửa văn bản**.
  - `essay_blind.go` (`StripIdentityLines`: chỉ xoá nguyên dòng `Họ tên / MSSV / Mã số / Email`, **không** placeholder — che / khôi phục tên, MSSV, email còn lại, kể cả bạn cùng lớp, là việc của gateway), `essay_late.go` (`LateDays` ⌈giờ trễ ÷ 24⌉ theo hạn HIỆN TẠI, `LatePenalty`, `TotalAfterLate`; decimal), `essay_prompt.go` (`EssaySchema` strict, `BuildEssayPrompt`: rubric + đáp án chuẩn chỉ ở system, bài làm trong `<<<BAI_LAM_<16 hex> … >>>` ngẫu nhiên mỗi lần, lượt 2 đảo thứ tự tiêu chí).
  - `essay.go`: `Grader.Run(ctx, courseID, resultID) (Outcome, error)`: đọc bối cảnh (`EssayGradeContext`) → trích văn bản (TXT / MD đọc thẳng; PDF / DOCX qua `TextExtractor` — `DoclingExtractor` gọi `ingest.Docling`, OCR lượt hai; NFC; > `GRADING_MAX_CHARS` → `TEXT_TOO_LONG`) → bỏ dòng danh tính → quét injection (trên văn bản gốc) → < `GRADING_MIN_CHARS` thì bài trống, **0 lời gọi LLM** → hai lượt **song song** (`llm.TaskGrading`, `LaneBatch`, temperature 0, `llm.WithIdentity{CourseID}`) → `Check` / `Merge` / trừ muộn / `ANSWER_ECHO` → ghi `DRAFT` (`ai_scores`, `ai_total_before_late` ghi một lần; `pass_detail` = `{c_i:{pass1,pass2}, total:{…}, _injection, _dropped}`). Lỗi vĩnh viễn (`EXTRACT_FAILED`, `TEXT_TOO_LONG`, `LLM_BUDGET_EXHAUSTED`, `GRADING_OUTPUT_INVALID`) ghi `FAILED` với tiêu chí `NULL` (không bao giờ 0 điểm); lỗi tạm trả `*TransientError` để hàng đợi (US-P7-07) thử lại. Không bao giờ tự công bố; `UPDATE … WHERE status = 'DRAFT'`.
  - `internal/store/queries/essay_grading.sql` (`EssayGradeContext`, `EssaySetExtract`, `EssaySaveDraft`, `EssaySaveFailed`).
- `go.mod`: `golang.org/x/text` đổi `// indirect` → trực tiếp (NFC).
