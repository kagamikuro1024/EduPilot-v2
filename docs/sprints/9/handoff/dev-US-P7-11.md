# Handoff — US-P7-11 (TeamsGraphSource + mock-graph)

## Máy chủ (đã làm)
- **Adapter (AC1, AC5):** `internal/submission/source/teams.go` — MỘT đường mã cho Graph thật và giả (chỉ khác `GRAPH_BASE_URL` / `GRAPH_AUTH_URL`; `TestTeamsAdapterHasNoMockBranch` quét: không có từ `mock` ngoài chú thích, không `os.Getenv`; `config.go` ở cùng gói là chỗ duy nhất đọc `config.Config`). Chuỗi gọi: token client-credentials (chỉ bộ nhớ, tái dùng tới `expires_in − 10 s`) → **một** lệnh phân trang `GET /education/classes/{id}/members` (id → `mail`, rồi `userPrincipalName`; không có `/users/{id}`) → `GET …/assignments/{aid}/submissions?$expand=submittedResources` (nextLink phải cùng host) → chỉ `status == submitted` → tải `submittedResources[].resource.fileUrl` song song ≤ `TEAMS_DOWNLOAD_PARALLEL` (4), callback `onFile` tuần tự. Lỗi: `429` chờ `Retry-After` (mặc định 1, trần 30) qua `Sleeper` tiêm được, ≤ `TEAMS_RETRY_MAX`; `401` xin token mới đúng một lần, `401` nữa → `TEAMS_AUTH_FAILED`; `403` → `TEAMS_CONSENT_REQUIRED`; JSON thiếu trường → `TEAMS_RESPONSE_INVALID`; mạng → `UNREACHABLE`; quá hạn → `TIMEOUT`. Tải tệp: host phải nằm trong `GRAPH_FILE_HOSTS` (rỗng = host của `GRAPH_BASE_URL`; sai → `FILE_HOST_NOT_ALLOWED`), chuyển hướng chỉ tới host liệt kê (≤ 5), **không gửi `Authorization` sang host khác host Graph**; 5xx thử lại `TEAMS_FILE_RETRY` (2) rồi lỗi riêng `FILE_DOWNLOAD_FAILED` (đợt tiếp tục); mạng đứt giữa chừng → dừng đợt `UNREACHABLE`. Không có lời gọi ghi nào về Teams.
- **Đồng bộ (AC2, AC7):** `internal/submission/teams.go` (`TeamsSync`): `POST …/assignments/{aid}/teams/sync` (TA, TEACHER; `Idempotency-Key`) → `Enqueue` (409 `TEAMS_DISABLED` | `TEAMS_NOT_CONFIGURED` | `CHANNEL_NOT_ALLOWED`; đang chạy → `job_id` cũ qua `ep:teamssync:{asg}:job`; ≤ 1 / `SYNC_NOW_MIN_INTERVAL` / bài → `429 + retry_after`) → việc `teams.sync` ở worker: khoá `ep:lock:teams:{asg}` (token riêng), `TEAMS_SYNC_TIMEOUT`, mỗi tệp → sniff + blob + `submission.Ingest` (nguồn `TEAMS`, `external_ref = graph submission id`, `external_ts = submitted_at = submittedDateTime`, `SenderVerified`, bộ khớp US-P7-04 theo email đã xác minh). Idempotent theo `(course, source, external_ref, external_ts)`; nộp lại → phiên bản mới; bản mới nhất đã `REVIEWED/PUBLISHED` → `UNMATCHED ALREADY_REVIEWED` (kiểm chung ở `Ingest`). Tiến độ: `jobs.result {fetched, total}` khi còn chạy ("Đã lấy k/n bài"), xong `{fetched, created, deduped, unmatched, failed:[{graph_submission_id, code}]}`; lỗi toàn đợt thành `UserError` có mã + câu tiếng thường (consent: "Cần quản trị Microsoft 365 của trường cấp quyền đọc bài tập và danh sách lớp.").
- **Cấu hình (AC6, AC8, AC10):** `GET/PUT …/integrations/teams`, `POST …/teams/test` (`mailin.Service.TeamsPut/TeamsTest`; `client_secret` AES-GCM, AAD `"{course}:TEAMS"`, chỉ ghi; `GET` = `Manage`, `PUT`/`test` = `Manage` + ADMIN; đồng bộ = `StaffRole`). `GET` kèm `sandbox` (host `GRAPH_BASE_URL` ≠ `graph.microsoft.com` → nhãn "Môi trường giả lập") và `available` (`TEAMS_ENABLED`). `test` xin token + `GET /education/classes`: `kind ∈ TEAMS_AUTH_FAILED | TEAMS_CONSENT_REQUIRED | TEAMS_RESPONSE_INVALID | UNREACHABLE | TIMEOUT`.
- **`cmd/mock-graph` (AC3, AC4):** thư viện `cmd/mock-graph/server` (+ `main.go`, cổng 8090, `-healthcheck`); không nhập `internal/*` (`TestMockGraphNotImported`). Endpoint: token (`expires_in: 60`, kiểm tenant / client), `classes`, `members`, `assignments`, `submissions` (`$expand`, `$top`, `@odata.nextLink` tuyệt đối cùng host), `files/{id}`; điều khiển `POST /__mock/scenario`, `GET /__mock/requests` (nhật ký + số lần xin token + số `429`), `POST /__mock/reset`. Kịch bản: `happy`, `paged`, `throttle`, `expired_token`, `no_consent`, `slow`, `partial_failure` (+ `unauthorized` để kiểm không vòng lặp).
- **Dữ liệu:** `node scripts/seed.mjs --mock-graph` (không cần stack) sinh `backend-go/testdata/mock-graph/*.json` + `files/` từ `fixtures/teams-plan.csv` (30 thành viên; 25 submitted gồm 1 email ngoài lớp, 3 working, 2 returned; giờ nộp = hạn BT03 + `hours_vs_due`; id bài nộp UUID v5 theo tài khoản). `backend-go/testdata/graph-docs/*.json` (có `_source` ở đầu) = ví dụ chép từ tài liệu Microsoft (List submissions, List members, List classes, token) + hình dạng `submittedResources` theo *educationSubmissionResource* / *educationFileResource* (tài liệu không có ví dụ đầy đủ cho `$expand=submittedResources`; ghi ở `_source`).
- **Cấu hình môi trường (AC11):** `TEAMS_ENABLED` (production mặc định `false`, ngoài production `true`), `GRAPH_BASE_URL`, `GRAPH_AUTH_URL` (production mặc định Graph thật + https; trỏ `mock*` hoặc http → gateway không khởi động, lỗi nêu tên biến), `GRAPH_FILE_HOSTS`, `TEAMS_DOWNLOAD_PARALLEL`, `TEAMS_FILE_RETRY`, `TEAMS_RETRY_MAX`, `TEAMS_SYNC_TIMEOUT`. `docker-compose.local.yml`: service `mock-graph` (target `mock-graph` trong `backend-go/Dockerfile`, healthcheck) + biến trên cho gateway và worker.
- **OpenAPI:** +4 thao tác (283 → **287**): `getTeamsIntegration`, `putTeamsIntegration`, `testTeamsIntegration`, `syncAssignmentFromTeams`; `IntegrationView.kind` thêm `TEAMS`, `sandbox`, `available`.

## Quyết định / lệch cần biết
- **`docker-compose.prod.yml` chưa tồn tại trong repo** (AC11 ghi `grep -c mock-graph docker-compose.prod.yml` → `0`): chỉ có `docker-compose.local.yml`, `.test.yml`, `.test-seed.yml`. Production không có service `mock-graph` vì compose production chưa được viết (thuộc phase PR); mặc định cấu hình + `TestProductionRejectsMockGraph` đảm bảo phía mã. `docker-compose.test-seed.yml` là override của gateway nên không khai báo `mock-graph` (service nằm ở `local.yml`, tới được qua `-f docker-compose.local.yml`).
- Bài nộp Teams không có tệp hợp lệ / sai đuôi / sai nội dung → lỗi riêng `NO_FILE` / `FILE_TYPE_NOT_ALLOWED` / `FILE_INVALID` (không làm hỏng đợt).
- Lệnh `Kiểm:` ghi `-tags integration`; repo không dùng tag đó (chạy với `-tags testroutes` hoặc không tag).
- Điểm lệch so với Graph thật: tệp tải qua `/files/{id}` của mock, không SharePoint (ghi cho luận văn).
