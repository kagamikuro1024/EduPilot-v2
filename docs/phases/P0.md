**Mục tiêu (D45 — viết mới toàn bộ):** dọn mặt bằng và dựng lưới an toàn trước khi viết tính năng: mã Project III dời vào `legacy/`, có khung chạy được của ba phần mới (Go gateway, Python AI, Next.js), stack local mới, CI, và kịch bản demo làm kim chỉ nam.

## Lát việc

**L0. Kịch bản demo là kim chỉ nam** (viết TRƯỚC khi code)
- [ ] `docs/DEMO_SCRIPT.md`: kịch bản 15 phút cho buổi bảo vệ, đi qua các luồng F2 → F3 → F5 → F7 → F9 → F10 → F17 bằng 2 lớp seed. Mỗi phase sau phải làm cho ít nhất một bước của kịch bản chạy thật; cuối mỗi phase chạy lại kịch bản tới bước xa nhất có thể
- [ ] Ghi rõ phương án dự phòng cho ngày bảo vệ: chế độ `DEMO_MODE=true` dùng provider `fake` trả lời đã ghi sẵn cho đúng các câu trong kịch bản (mạng hay API hỏng vẫn demo được) + video quay sẵn

**L1. Dọn mặt bằng + khung mới**
- [ ] `git mv` mã Project III vào `legacy/` (backend-java, src, frontend cũ, shared-proto, db, data_pipeline, huggingface, Dockerfile*, docker-compose*.yml cũ, requirements*.txt, spec.md, improve_UI.md, README cũ…). GIỮ ở chỗ cũ: `docs/`, `.claude/`, `CLAUDE.md`/`AGENTS.md`, `scripts/team-up.sh`, `scripts/ui-antipatterns.sh`, `frontend/src/shared/styles/tokens.css`, `frontend/public/brand/`
- [ ] `backend-go/`: `go.mod`, `cmd/gateway` (chi, `slog`, `GET /healthz`, cấu hình từ env), `api/openapi.yaml` mô tả `/healthz`, test
- [ ] `src/` Python AI mới (3.11): gói tối thiểu + `pyproject.toml`, `pytest -q` xanh, healthcheck
- [ ] `frontend/` Next.js mới dùng `tokens.css` + font Be Vietnam Pro, một trang trống tiếng Việt; `lint` + `build` xanh
- [ ] `docker-compose.local.yml` mới: postgres + pgvector, redis, minio, mailhog (SMTP 1025, UI 8025), gateway, ai, frontend; mọi service có healthcheck; `pnpm dev` / `dev:status` / `dev:down` chạy với stack mới

**L2. CI**
- [ ] `.github/workflows/ci.yml`: Go (`go vet`, `golangci-lint`, `go test -race`), Python (`pytest -q`), frontend (`lint`, `build`, `bash scripts/ui-antipatterns.sh`); không chạy gì trong `legacy/`; không gọi LLM thật
- [ ] Test đỏ → CI đỏ (không `continue-on-error`)

## Cổng nghiệm thu
```bash
pnpm dev && pnpm dev:status            # mọi container healthy, MailHog ở :8025
curl -fsS localhost:8080/healthz       # gateway Go trả 200
gh run list --branch sprint/1-p0-prep --limit 1   # CI xanh
test -s backend-go/api/openapi.yaml
test -s docs/DEMO_SCRIPT.md
test -d legacy/backend-java && test ! -d backend-java
```

## Bạn tự kiểm
- Mở `http://localhost:3000`: trang trống đúng font và màu thương hiệu.
- Mở `http://localhost:8025`: thấy MailHog.
- Đọc `docs/DEMO_SCRIPT.md`: đọc to thử, có vừa 15 phút không.
