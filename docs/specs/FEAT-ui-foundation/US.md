## Quy ước kiểm chung

```bash
# Chạy ở gốc repo. Frontend cần Node 24 + pnpm; gate chạy trên BẢN BUILD, không phải `next dev`.
FE="pnpm -C frontend"
PW="$FE exec playwright test"
BASE=http://localhost:3300
# build cho gate: mở /dev/*, giữ màn mock, bật cổng dán token dev (SRS 8.1). Bản này KHÔNG dùng để triển khai.
gbuild() { NEXT_PUBLIC_DEV_TOOLS=1 NEXT_PUBLIC_DEV_AUTH=1 NEXT_PUBLIC_MOCK_SCREENS=1 $FE build; }
gstart() { $FE exec next start -p 3300; }                        # chạy nền khi kiểm tay
# build "như production": không /dev/*, không cổng token dev
pbuild() { NEXT_PUBLIC_MOCK_SCREENS=1 $FE build; }
# gateway thật (chỉ cho test gắn @real): stack sprint 2 dựng bằng docker-compose.test.yml (route thử + job)
GW=https://localhost                                               # qua Caddy, luôn thêm -k
tok() { (cd backend-go && JWT_SECRET_KEY="$SECRET" go run ./cmd/gateway token --role "$1" ${2:+--sub "$2"} "${@:3}"); }
```

Playwright nằm ở `frontend/e2e/` (`playwright.config.ts`: dự án `desktop` 1440 × 900 và `mobile` 390 × 844, `webServer` = `next start -p 3300`). Test gắn `@real` cần gateway thật và **không chạy trong CI** (CI không dựng stack); QC chạy tay khi cổng PU. Lệnh `AUDIT`, `TOUCH`, `LEFT` là đoạn Console nguyên văn của QC 1.5 (`docs/sprints/1.5/qc/scripts/audit.mjs`, xuất `AUDIT_SRC`, `TOUCH_SRC`, `LEFT_SRC`); trong spec này "AUDIT sạch" = trả `{ ox: 0, cut: [], ell: [] }`. Mọi test hình ảnh đóng băng đồng hồ bằng `page.clock` và tắt animation. **CORS cho cổng:** frontend gate chạy ở `http://localhost:3300` còn gateway ở `https://localhost` (khác origin; sprint 3 dùng header `Authorization`, chưa có cookie), nên `CORS_ORIGINS` của stack test (`docker-compose.test.yml`) phải gồm `http://localhost:3300`; QC dùng Chrome riêng (profile tạm) với `--ignore-certificate-errors` cho chứng chỉ tự ký của Caddy. `NEXT_PUBLIC_API_URL` là biến **lúc build** (đổi thì build lại; không có tham số URL `?api=` — Q-QC-PU03-1).
